This code reads data from a serial port on your device and displays that data in graphical form. If it isn't working, check that no other program is using the port that the experiment is plugged into (could be arduino IDE or other programs like it).

**HOW TO USE** 
1) plug in the arduino with the sensor wired in to a port on the computer.
2) click "connect" in the top right corner of the program and select the correct port.
3) select a reasonable timescale and the data should be rolling in. :)

Here is the link to the working program: (https://goosethepigeon.github.io/Temperature-Sensor-Data-Code/ir-sensor-graph.html) Use this.
